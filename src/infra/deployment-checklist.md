# Deployment Checklist

아키텍처 경계와 런타임 계약의 일관성을 점검하기 위한 체크리스트입니다.

## 1) 아키텍처 경계

- [ ] 환경 간 리소스 경계가 명확한가
- [ ] 데이터 저장소와 메시징 경로의 책임이 분리되어 있는가
- [ ] HTTP/Worker 역할 분리가 진입점 계층에서만 결정되는가

## 2) 애플리케이션 계약

- [ ] Worker/Dispatcher가 내부 구현을 우회하지 않고 Command/Query 경계를 따르는가
- [ ] Outbox 전달 경로가 도메인 상태 변경과 분리된 계약으로 유지되는가

## 3) 스케줄 계약

- [ ] Outbox dispatch scheduler 주기가 문서/템플릿/환경 예시에서 일관적인가
- [ ] 주기 변경 시 최대 전달 지연 증가가 문서에 반영되어 있는가

## 4) 문서 품질

- [ ] 실행 절차 중심 설명보다 설계 의도와 경계 설명이 우선되는가

## 5) Lambda/SAM 계약 일관성

- [ ] SAM `Handler` 경로와 실제 빌드 산출물 경로가 일치하는가
- [ ] 템플릿 파라미터(stage, region, resource name)가 배포 스크립트 인자와 동일한 계약을 따르는가
- [ ] 환경별 변수 예시 파일과 템플릿 요구 변수 목록이 동기화되어 있는가
