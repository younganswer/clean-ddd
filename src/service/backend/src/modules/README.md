# modules

`modules/`는 도메인별 구현체를 담는 디렉터리입니다.

<br/>
<br/>

## 현재 모듈

- `users`: 사용자 계정/식별/프로필 규칙
- `ordering`: 주문 생성/상태 전이 규칙
- `payments`: 결제 결과 반영/정합성 규칙
- `shipping`: 배송 상태/이벤트 처리 규칙
- `inventory`: 재고 가용성/동시성 완화 규칙
- `outbox`: 트랜잭션 경계 내 이벤트 기록/발행 연결 규칙

<br/>
<br/>

## 정리 관점

- 각 모듈은 자체 규칙/모델/유스케이스를 캡슐화합니다.
- 모듈 간 연동은 이벤트/계약을 통해 느슨하게 연결합니다.
- 비동기 후속 처리는 outbox + queue 흐름으로 분리합니다.
