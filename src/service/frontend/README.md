# frontend

`src/service/frontend`는 Next.js 기반의 어드민 UI입니다.

이 저장소의 프론트엔드는 “정적 export 결과물을 배포(S3 + CloudFront)”하는 형태를 전제로 구성되어 있습니다. 로컬 개발에서는 Next dev server로 실행됩니다.
