# Nest 애플리케이션 모델

이 문서는 clean-ddd 백엔드가 NestJS 애플리케이션을 어떤 형태로 부팅하고 실행하는지 소개합니다.

## 개요

Nest 애플리케이션은 크게 두 가지 형태로 실행될 수 있습니다.

- HTTP 서버로 실행(포트 리스닝)
- 애플리케이션 컨텍스트로 실행(리스닝 없이 DI 컨테이너/모듈만 구동)

이 저장소에서는 프로세스 역할에 따라 위 두 형태를 조합합니다.

## 이 저장소에서의 형태

- HTTP API 역할은 포트 리스닝이 활성화됩니다.
- Cron/Queue 역할은 리스닝 없이 내부 작업(스케줄, 폴링)을 수행하도록 구성됩니다.

또한 기본 API 경로는 `/api/v1` 프리픽스를 사용합니다.

## 범위 밖(Non-goals)

- NestJS의 일반 튜토리얼(Controller/Provider/Module 기초)
- 각 모듈의 비즈니스 유스케이스 설명
