# clean-ddd

주문 도메인을 예시로 DDD + Clean Architecture를 적용한 샘플 서비스입니다.

## 목표

- Backend: NestJS + MikroORM + Neon(PostgreSQL)
- Event: Outbox 패턴 + 단일 SQS FIFO 큐(`OutboxDispatchQueue.fifo`)
- Compute: AWS on-demand(HTTP: API Gateway + Lambda, Async: SQS + Lambda)
- Frontend: Next.js(Admin) → S3 정적 배포 + CloudFront

## 저장소 구조

- apps/api: 백엔드(NestJS)
- apps/admin: 어드민(Next.js)
- packages/contracts: API 계약(OpenAPI 등) 및 공용 타입(도메인 객체는 공유하지 않음)

## 개발 환경

이 워크스페이스는 전역 `pnpm` 설치 없이도 동작하도록 `shims/pnpm`을 제공합니다.

```bash
export PATH="$PWD/shims:$PATH"
pnpm -v
```

## 로컬 실행(개발)

### 1) SQS(LocalStack)

```bash
docker compose -f docker-compose.local.yml up -d
```

로컬 큐 URL 예시:

```text
http://localhost:4566/000000000000/OutboxDispatchQueue.fifo
```

### 2) API

- 환경 변수: [apps/api/.env.example](apps/api/.env.example)

```bash
export PATH="$PWD/shims:$PATH"
cd apps/api

# Neon 연결 문자열을 실제 값으로 세팅
export DATABASE_URL_POOLED='...-pooler...'
export DATABASE_URL_DIRECT='...'

# LocalStack SQS
export AWS_REGION=ap-northeast-2
export SQS_OUTBOX_QUEUE_URL='http://localhost:4566/000000000000/OutboxDispatchQueue.fifo'

pnpm dev
```

### 3) Admin

- 환경 변수: [apps/admin/.env.example](apps/admin/.env.example)

```bash
export PATH="$PWD/shims:$PATH"
cd apps/admin
export NEXT_PUBLIC_API_BASE_URL='http://localhost:3000/api/v1'
pnpm dev
```

## DB 마이그레이션

Neon direct URL을 우선 사용합니다.

```bash
export PATH="$PWD/shims:$PATH"
cd apps/api
export DATABASE_URL_DIRECT='...'
pnpm db:migration:create
pnpm db:migrate
```
